# Setup
1. Set up venv in decompai directory `python -m venv venv`
2. Use venv `source venv/bin/activate`
3. Install packages `pip install -r requirements.txt`
4. Set GEMINI_API_KEY environment variable before running
    1. For VSCode, copy .env.template to .env and set your Gemini API key in .env
    2. For bash, export GEMINI_API_KEY=your_key_here
